## 🌌 Overview

**NEURO-SCRAP** is an interactive, first-person 3D sci-fi puzzle game set amidst the wreckage of a crashed exploratory starship on a desolate alien world. 

Trapped under a black sky dominated by a Gargantua-style Schwarzschild black hole and rotating celestial giants, the player must explore the crash site, scavenge corrupted diagnostic terminals, and systematically repair the damaged neural processing core of **Sylva**—an autonomous solarpunk quadruped scrap robot.

By repairing Sylva's corrupted memory banks, sensor decoders, and synaptic relays, the player learns fundamental **Data Science**, **Feature Engineering**, **Linear Classifiers**, and **Deep Neural Networks** from first principles through direct visual and tactile mechanics.

### 🛸 Prologue: The Impact at the Edge of the Void
An interstellar research spacecraft experiences catastrophic telemetry failure while executing an exploratory transit through an uncharted cosmic sector. Pulled into the gravitational gradient of an ancient Schwarzschild black hole, the vessel shears apart and crash-lands across the basalt regolith of an airless exoplanet.

The player awakens as the sole surviving expedition engineer amidst scattered titanium bulkheads, shattered photovoltaic arrays, and smoking rocket engine exhaust cones. The primary navigation transceivers are offline, and the emergency beacon is dead. The only hope of surviving and contacting deep space lies in the ruined chassis of **Sylva**, the expedition's autonomous robotic scout.

---

### ⚙️ Chapter 1: Command Core B — Exploratory Data Science & Telemetry
Upon accessing the ship's auxiliary server bank (**Command Core B**), the player discovers that raw astronomical sensor feeds are flooded with cosmic background noise. 

* **The Mission**: Re-calibrate the sensor channels to distinguish between harmless cosmic static, orbiting exoplanets, stellar beacons, and the lethal accretion fluctuations of the nearby black hole.
* **The Gameplay**: 
  * Analyze raw 1D telemetry number lines and 2D scatter plots.
  * Extract statistical features: **Jumpiness** (temporal signal variance) and **Brightness** (spectroscopic intensity).
  * Use median ticks, variance bounds, and cluster bounding lanes to classify unknown astronomical readings.
* **The Insight**: Data science is the art of turning raw, noisy numbers into structured geometric coordinates that reveal hidden physical reality.

---

### ⚡ Chapter 2: The Signal Relay Bench — Perceptrons & Decision Boundaries
With raw sensor telemetry cleaned, the player ventures into the cargo deck to reconnect the ship's damaged **Signal Relay Hub**. Here, the ship's navigational guidance system must learn to categorize incoming signals in real time without human intervention.

* **The Mission**: Wire hardware relay switches and configure an **Oracle Bias HUD** to compute automatic classification boundaries.
* **The Gameplay**:
  * Tune synaptic weights ($w_1, w_2$) and bias offsets ($b$) along physical circuit potentiometers.
  * Adjust linear decision boundaries ($w_1 x_1 + w_2 x_2 + b = 0$) to cleanly partition target transmission frequencies from false stellar noise.
  * Verify true positive vs. false positive classification rates on the diagnostic oscilloscope.
* **The Insight**: A single artificial neuron (perceptron) is fundamentally a geometric plane that splits a universe of data into distinct decisions.

---

### 🧠 Chapter 3: The Neural Core — Non-Linear Separation & Multi-Layer Networks
Moving into the vessel's primary avionics bay, the player interfaces with Sylva's damaged central brain: **The Neural Core**. The challenges here can no longer be solved by straight lines; the celestial noise patterns form concentric rings, interlaced spirals, and non-linear manifolds that defeat single-layer perceptrons.

* **The Mission**: Construct multi-layer feedforward neural networks to solve complex, non-linearly separable classification topologies.
* **The Gameplay**:
  * Stack hidden layers and configure activation functions (**ReLU**, **Sigmoid**, **Tanh**) to fold and bend high-dimensional coordinate space.
  * Observe the loss landscape in real time as backpropagation and gradient descent optimize synaptic weights.
  * Solve the classic XOR and concentric manifold dilemmas to fully restore Sylva's cognitive awareness.
* **The Insight**: Deep learning succeeds because hidden layers warp and distort coordinate space until impossible problems become linearly solvable.

---

### 📡 Chapter 4 & Epilogue: Full Convergence & The Grand Transmission
With Sylva's brain fully reconstituted, the robotic companion stands, powers its glowing dual-optic lenses, and initiates the planetary uplink sequence. Together, player and robot sync the ship's high-gain antenna pedestal with the planetary relay satellite, broadcasting an encrypted distress beacon into the deep-space void.

## 🎓 Educational Framework — How NEURO-SCRAP Teaches ML

Unlike typical tutorials that treat machine learning as abstract mathematical formulas in a Jupyter notebook, NEURO-SCRAP grounds every concept into visual, spatial, and mechanical systems:

| Machine Learning Concept | In-Game Manifestation | Mechanical Intuition |
| :--- | :--- | :--- |
| **Features** | Astronomical Sensor Channels (Jumpiness, Brightness) | Independent geometric dimensions on a coordinate grid |
| **Data Cleaning** | Noise Scrubbing in Command Core B | Filtering outliers and clustering observations |
| **Linear Perceptron** | Signal Relay Switch & Oracle Bias HUD | A mechanical line dividing two regions of space |
| **Weights & Biases** | Circuit Potentiometers & Dial Offsets | Slope/angle of the boundary line and its distance from the origin |
| **Activation Functions** | Nonlinear Valve Gates (ReLU, Sigmoid) | Introducing curves and thresholds into rigid mathematical transformations |
| **Multi-Layer Networks** | The Neural Core Circuitry | Folding coordinate space so intertwined classes can be separated |
| **Loss & Convergence** | Diagnostic System Repair Integrity % | Measuring error distance and minimizing it toward zero |

## 🎨 Visual & Atmospheric Architecture

### 1. ThreeUI Procedural Living World (`SylvaLivingWorld`)
The title screen features a real-time procedural 3D living ecosystem:
* **Custom GLSL Shaders**: Procedural gnarled bark roots, simplex noise wind sway, dynamic grass fur blades, and procedural flower geometry.
* **Scan-Pulse Reveal**: When the page loads, an expanding holographic wireframe survey wave scans across the terrain, progressively revealing the moss, foliage, and pollen motes.
* **Articulated Solarpunk Scrap Robot**: Perched upon the peak crest of the moss arch, Sylva watches and dynamically tracks your cursor in full 3D space with inverse kinematic neck rotations, idle breathing, and acoustic chirps when clicked.

### 2. Neon Noir UI Design System
Inspired by *Blade Runner* and industrial retro-futurism:
* **Chamfered Clip-Path Geometry**: Diagonal corner-cut panels and interactive buttons with zero boxy card clutter.
* **Dual SVG Border Beams**: High-frequency animated laser pulses tracing button perimeters.
* **Strict Accessibility**:
  * Colorblind simulation filters (**Protanopia**, **Deuteranopia**, **Tritanopia**).
  * High-contrast grayscale mode.
  * Full `prefers-reduced-motion` support (collapsing animated sweeps into instantaneous fades).
  * WCAG AAA compliant text contrast ratios ($\ge 7.7:1$).

## 🚀 Getting Started

### Prerequisites
* [Node.js](https://nodejs.org/) (version 18.18.0 or higher recommended)
* `npm` or `pnpm`

### Installation & Local Setup

```bash
# Clone the repository
git clone https://github.com/MagnusKalicharan/neuroscrap.git

# Navigate into the project root
cd neuro-scrap

# Install project dependencies
npm install

# Start the local development server (with Turbopack)
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to experience the landing page. Click **PLAY GAME** to enter the 3D crash site.

### Verification & Testing Commands

```bash
# Run TypeScript compilation check
npx tsc --noEmit

# Run automated Scene 1 unit tests
npm test

# Build production bundle
npm run build

# Start production server
npm run start
```
